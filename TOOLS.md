# Windows Toolkit — curated tools

> Official sources only. Install most via `scripts/winget-bundle.ps1`.

## 📁 File & disk
- [TeraCopy](https://www.codesector.com/teracopy) — fast, verified file copy
- [7-Zip](https://www.7-zip.org/) — archiver
- [Everything](https://www.voidtools.com/) — instant file search (voidtools)
- [WinDirStat](https://windirstat.net/) — disk usage
- [TreeSize Free](https://www.jam-software.com/treesize_free) — folder sizes

## 🧹 Debloat & privacy
- [Win10Privacy](https://www.win10privacy.de/) — granular privacy/telemetry control
- [O&O ShutUp10++](https://www.oo-software.com/en/shutup10) — privacy hardening
- [BleachBit](https://www.bleachbit.org/) — clean junk & free space
- [privacy.sexy](https://privacy.sexy/) — scriptable Windows hardening
- (sibling) [Cognis privacyspoof](https://github.com/cognis-digital/privacyspoof) — blocklists + UA/geo spoofing

## 🗑️ Uninstallers
- [Revo Uninstaller](https://www.revouninstaller.com/) — deep uninstall + leftovers
- [BCUninstaller](https://github.com/Klocman/Bulk-Crap-Uninstaller) — bulk uninstall (OSS)

## 💿 Boot, recovery & imaging
- [Hiren's BootCD PE](https://www.hirensbootcd.org/) — recovery PE ([tool list](https://www.hirensbootcd.org/hbcd-pe-x64/))
- [Ventoy](https://www.ventoy.net/) — multiboot USB
- [Rufus](https://rufus.ie/) — bootable USB creator
- [Macrium Reflect Free](https://www.macrium.com/) — disk imaging
- [Clonezilla](https://clonezilla.org/) — disk cloning

## 🔧 UEFI / firmware
- [UEFITool](https://github.com/LongSoft/UEFITool) — UEFI image editor
- [CHIPSEC](https://github.com/chipsec/chipsec) — platform security assessment
- [HWiNFO](https://www.hwinfo.com/) — hardware info & sensors

## 🛠️ Power-user utilities
- [Microsoft PowerToys](https://github.com/microsoft/PowerToys) — FancyZones, Run, etc.
- [Sysinternals Suite](https://learn.microsoft.com/sysinternals/) — Autoruns, Process Explorer, etc.
- [System Informer](https://systeminformer.sourceforge.io/) (Process Hacker) — advanced task manager
- [ShareX](https://getsharex.com/) — screenshots & screen recording
- [Notepad++](https://notepad-plus-plus.org/) — text editor
- [Windows Terminal](https://github.com/microsoft/terminal) — modern terminal

## 📦 Package managers
- [winget](https://learn.microsoft.com/windows/package-manager/) — built-in
- [Chocolatey](https://chocolatey.org/) — package manager
- [Scoop](https://scoop.sh/) — portable package manager
- [UniGetUI](https://github.com/marticliment/UniGetUI) — GUI for winget/scoop/choco
